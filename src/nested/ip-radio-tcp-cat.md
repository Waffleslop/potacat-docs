# IP Radio (TCP CAT)

**Best for:** FlexRadio on a remote PC, or any radio with a TCP-based Kenwood CAT interface. For an Elecraft K4 over the network, use **K4 Remote (network)** instead; see [Elecraft Rigs](rig-elecraft.md).

1. Add a new rig → select **IP Radio (TCP CAT)**
2. Enter the host IP and port
3. Save
